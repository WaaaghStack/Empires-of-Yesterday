Place all marine portrait PNG files in this folder.

Examples:
  marine_portrait_01_black_male_buzzcut.png
  marine_portrait_02_white_female_ponytail.png

If your files are in the project root or assets/ folder, run from the project folder:
  powershell -ExecutionPolicy Bypass -File move_portraits.ps1

Godot will import them automatically when they appear here.
